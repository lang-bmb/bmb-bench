# Third-party sources

Some task sets are derived from other projects. Each keeps the license of its source, and the license text
travels with the set.

| Set | Source | License | Where the license text is |
| --- | --- | --- | --- |
| `brb-hard` | QuixBugs (D. Lin, J. Koppel, A. Chen, A. Solar-Lezama, "QuixBugs: A Multi-Lingual Program Repair Benchmark Set Based on the Quixey Challenge", SPLASH Companion 2017; <https://github.com/jkoppel/QuixBugs>) | MIT | `brb-hard/QUIXBUGS-LICENSE` |
| `bvb` and its variants | public Verus tasks (Verus-Bench, Vericoding), pinned commits and selection record in `bvb/sources.py` | as recorded per source | `bvb/licenses/` |

This table is completed when the sets are moved: every set is checked for a source outside the project.
