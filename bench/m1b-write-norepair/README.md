# m1b-write-norepair (H-REPAIR ablation variant)

A variant that `bench/repair/gen.py` makes from `bench/m1b-write` (frozen). It is not edited by hand; the generator makes it again. The one difference from m1b-write is `"tool_filter": "no-repair"` in `set.json`: the m1 harness removes, from every tool result that goes to the model, the counterexample at the end of a diagnostic message (`; counterexample: ..`, `; unconfirmed counterexample: ..`), every `fix` (suggested fixes and hints) and every `counterexample` field. The prompt, seed, tasks, mutants, judging and limits are byte for byte those of m1b-write. The verdict rule is in `bench/repair/README.md`.
