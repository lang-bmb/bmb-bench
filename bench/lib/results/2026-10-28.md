# Library speed and size (2026-10-28)

- Environment: Intel(R) Xeon(R) Processor @ 2.80GHz (4 cores), Linux-6.18.44-fc-v180-x86_64-with-glibc2.39
- Tools: rustc 1.97.0 (2d8144b78 2026-07-07); Ubuntu clang version 18.1.3 (1ubuntu1); bmb `build` (clang -O2)
- Method: the median (wall clock) of 9 interleaved runs per variant. Measured after the outputs were checked to agree. Size is that of the stripped executable.
- Compared with: for utf8, the Rust standard library's `std::str::from_utf8`; for sha256, safe Rust of the same algorithm (standard library only).
- A ratio < 1 means BMB is faster.
