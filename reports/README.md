# Reports

The measurement reports belong here: for each measurement its conditions, tables, verdict and limits, written
from the result rows under `bench/<set>/results/`. They were written in Korean in the project's working
repository and are being translated; they will land in this directory, each naming the commits it measured.
Until then the rows themselves, and the short result notes that some sets keep beside them
(`bench/<set>/results/*.md`, `bench/<set>/README.md`), are what this repository holds.
